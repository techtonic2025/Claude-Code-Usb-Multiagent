# /dev — Avvia l'agente Developer
Usa l'agente developer per scrivere codice, fixare bug o implementare feature.

## Cosa fa
Carica l'agente `developer` e lo mette a disposizione per:
- Scrivere nuovo codice
- Modificare codice esistente  
- Fixare bug
- Implementare feature
- Fare refactoring

## Esempi
/dev Crea una pagina di login con React e TypeScript
/dev Fixa il bug nel modulo autenticazione
/dev Aggiungi test per l'API degli utenti
