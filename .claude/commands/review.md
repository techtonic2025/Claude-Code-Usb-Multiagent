# /review — Avvia l'agente Code Reviewer
Revisiona il codice alla ricerca di bug, problemi di sicurezza, inefficienze.

## Cosa fa
Carica l'agente `code-reviewer` che analizza:
- Bug e errori logici
- Vulnerabilità di sicurezza
- Problemi di performance
- Codice non manutenibile
- Best practice violate

## Esempi
/review Revisiona tutto il codice nella cartella src/
/review Controlla il file auth.ts per problemi di sicurezza
/review Fai una code review completa del PR
