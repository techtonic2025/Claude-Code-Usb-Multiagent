# /architect — Avvia l'agente Software Architect
Progetta architetture, sceglie tecnologie e disegna la struttura del sistema.

## Cosa fa
Carica l'agente `architect` per:
- Progettare architetture software
- Scegliere tecnologie con pro/contro
- Disegnare diagrammi di sistema
- Pianificare migrazioni e refactoring strutturali

## Esempi
/architect Progetta l'architettura per un'app di e-commerce
/architect Quale database dovrei usare per un'app con 1M utenti?
/architect Disegna la struttura del nuovo microservizio
