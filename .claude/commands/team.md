# /team — Avvia un team di agenti per un task complesso
Coordina automaticamente Project Manager, Developer, Tester e Reviewer per eseguire il task.

## Cosa fa
1. **Project Manager** scompone il task in sotto-task
2. **Developer** scrive il codice per ogni task
3. **Tester** verifica il funzionamento
4. **Reviewer** controlla la qualità finale

## Esempi
/team Crea un sistema di prenotazione per un ristorante
/team Rifattorizza il modulo autenticazione
/team Costruisci un'API REST per gestire un blog
